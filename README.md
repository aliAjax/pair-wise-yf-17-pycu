# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

做一个给管风琴维护人员使用的音管调音记录前端项目，可以记录教堂或音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注。页面需要有音栓列表、调音偏差表、温湿度记录、异常音管标记和单次维护报告页。

## 功能

- **单次维护流程**：新建维护后先填场馆名称、温度、湿度，再逐根录入音栓、音管编号、音高、音分偏差、簧片状态和维修备注
- **异常清单**：偏差超过 ±10 音分或簧片状态异常（需微调/异常）的音管自动进入异常清单
- **复测**：异常音管可录入复测结果，合格后标记「已恢复」，初测与复测前后结果均保留
- **维护报告**：按音栓汇总音管数、异常数、已恢复/未恢复数，附异常前后明细与缺项清单，可导出文本报告
- **草稿与完成**：记录不全可先存草稿，报告列出缺项；缺项补全后点「结束维护」才算完成，未结束的会话不计入完成
- **数据持久化**：所有记录保存在浏览器 localStorage，重开页面仍在；首次打开自带 3 条样例维护记录
