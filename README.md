# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

做一个给管风琴维护人员使用的音管调音记录前端项目，可以记录教堂或音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注。页面需要有音栓列表、调音偏差表、温湿度记录、异常音管标记和单次维护报告页。

## 功能

- **现场录入工作台**：一次维护先填场馆名称和温湿度，再逐根录入音栓、音管编号、音高、音分偏差、簧片状态和维修备注。
- **异常清单**：音分偏差超过 ±10 音分或簧片状态异常的音管自动进入异常清单，无需手工另开表。
- **复测保留前后结果**：异常音管可多次复测，初测与每次复测结果全部保留；复测合格（偏差不超限且簧片正常）后记为“已恢复”。
- **单次维护报告**：按音栓汇总录入数、异常数、已恢复数和待复测数，并列出维护信息与音管记录的缺项。
- **草稿与完成**：记录不全也可随时保存草稿；只有点“结束维护”才算完成，未结束的维护一律标记为草稿、不计完成。
- **数据持久化**：所有场次（含保留的样例场次）存储在浏览器 localStorage，新数据重开页面仍看得到。
